# Tài liệu raw

Tài liệu gốc của dự án. Giữ nguyên, không chỉnh sửa. Đây là đầu vào để viết proposal và spec trong `openspec/`.

| Thư mục | Nội dung |
|---|---|
| `requirements/` | Yêu cầu nghiệp vụ, brief, ghi chú họp |
| `references/` | Quy định, tài liệu tham khảo, bài viết |
| `samples/` | Dữ liệu mẫu (csv, xlsx, json...) |

Ưu tiên định dạng `.md`, `.txt`, `.csv`, `.pdf` để agent đọc được trực tiếp.
